CLL-TIM installation

See README.md for the quick start and docs/USAGE.md for the full guide.

From a Conda terminal, in the repository root:

conda env create -f environment-pipxgboost.yml
conda activate clltim_calc_env
python examples/verify_install.py

For a direct run:
python CLLTIM_MobileVer2.py

Spyder is optional. If using an IDE, select the Python interpreter inside
clltim_calc_env; do not switch back to base before running the application.

This legacy runtime was checked in an existing Windows environment. A fresh
installation on every platform has not been established.
